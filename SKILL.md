# Continuous-material PPT

Use this skill for strategy, product, research, and validation decks that need a calm, premium, continuous-material visual system rather than a dashboard or generic corporate template.

## Workflow

1. Read `references/visual-system.md` and `references/page-types.md`.
2. Define the audience, decision, slide count, and one takeaway per slide.
3. Use `assets/templates/continuous-material-template.pptx` as the primary visual reference. Keep text editable and use stable Windows fonts.
4. Use real supplied evidence only. Integrate evidence into the composition; do not invent outcomes, customers, metrics, or quotes.
5. Put the full talk track, evidence boundaries, timing, transitions, and a `[Sources]` block in speaker notes.
6. Render every slide and apply `references/qa-rules.md` before delivery.

The bundled `assets/examples/continuous-material-example.pptx` is a generic reference example, not a content source. Do not use isolated white-background 3D-object layouts as the default direction.

## Portable use

This repository is self-contained. An agent may use the Markdown references and PPTX assets directly, even without a native Skill system. Keep project-specific content outside this repository.
